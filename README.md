## How to Calculate PSU Wattage

Add up the TDP (Thermal Design Power) of every component, then add 20–25% headroom for power spikes and future upgrades.

```
Recommended PSU = (CPU TDP + GPU TDP + Other Components) × 1.25

Example:
- Ryzen 7 7800X3D: 120W
- RTX 4080 Super: 320W
- RAM (2 sticks): 10W
- Motherboard: 50W
- SSD × 2: 10W
- Case fans × 4: 10W
- Total: 520W × 1.25 = 650W recommended
```

Always round up to the next standard PSU size (550W, 650W, 750W, 850W, 1000W, 1200W).
